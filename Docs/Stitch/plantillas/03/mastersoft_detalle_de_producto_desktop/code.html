Potencia directiva y máxima inmunidad al ruido en enlaces 5GHz

El Ubiquiti PowerBeam M5 (PBE-M5-400) integra el radio directamente en la bocina de alimentación del reflector (tecnología InnerFeed®), eliminando por completo la necesidad de cables coaxiales de RF. Esto minimiza las pérdidas por atenuación del cable y entrega una relación costo-beneficio inmejorable para enlaces troncales WISP e interconexión de sedes corporativas.

Equipado con la tecnología de procesamiento airMAX TDMA con protocolo propietario de Ubiquiti, permite que cada estación transmita y reciba usando ranuras de tiempo previamente asignadas, solucionando el histórico problema del nodo oculto y manteniendo latencias uniformes aún con alto tráfico.
